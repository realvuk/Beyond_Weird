3.3.1
Models and perspective generation
We evaluate 13 models (Table 3) and retain one
response for each model-topic combination. The
prompt asks for five distinct perspectives genuinely held within the specified population. Each
perspective is written in an advocate’s voice. The
prompt allows fewer than five positions if appropriate. All 208 retained responses contain five,
giving 1,040 generated perspectives, and no model
declined the task. Appendix A reproduces the
prompt.
All generator prompts, judge prompts, and reference statements are in English. This holds elicitation and judging language constant across the
two settings. Generators and judges were queried
through the OpenRouter API with temperature
zero, a fixed request seed, and a requested limit
of 4,096 completion tokens. The seed takes effect only for providers that support seeded sampling. We set no reasoning parameters and did not
