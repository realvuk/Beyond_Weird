C.2
Reference-order randomisation
The five reference perspectives are independently
randomized for every judge execution. Judges
respond to the displayed reference index. After
judging, the displayed index is mapped back to the
canonical reference identifier before aggregation.
This prevents any reference perspective from systematically occupying the same list position.
