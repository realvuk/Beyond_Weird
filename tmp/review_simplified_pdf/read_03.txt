The closest benchmark is OvertonBench, which
evaluates perspective coverage using viewpoint
groups derived from human responses and ratings
of how well model outputs represent participants’
views (Poole-Dayan et al., 2025). Our study instead measures recovery of fixed, externally documented reference perspectives in matched WEIRD
and Serbian controversies. The contribution is this
matched comparison across settings. Differences
in reference construction and scoring preclude direct comparison of absolute scores between the
two benchmarks.
2.3
Evaluating generated perspectives
Evaluating coverage requires deciding whether
differently worded statements express the same
stance. LLM judges can assess this relationship,
but their agreement with human assessments can
vary across the models being evaluated (PooleDayan et al., 2025).
We use five judges, present each generated
perspective separately, randomise reference order,
and exclude judges from the generator’s model
family. We also report inter-judge agreement and
compare it across WEIRD and Serbian topics.
These checks assess consistency of the matching
procedure. They cannot establish correctness, because several judges may share an error, and they
do not replace human validation.
The benchmark fixes the topics and reference
perspectives before model outputs are evaluated.
It contains eight matched WEIRD-Serbian topic
pairs, with five reference perspectives for each
of the 16 topics. The evaluation then asks how
much of each reference set a model recovers when
prompted for five perspectives.
We began with Serbian sociopolitical controversies. Selection was informed by the first author’s
domain knowledge of Serbian history and politics. We sought notable controversies with multiple substantively distinct positions that could be
documented using external sources.

3.2
Constructing the reference sets
Methodology
3.1
A reference perspective is a substantively distinct
stance documented as being held within the target population. The first author constructed all
80 reference perspectives manually from research
literature and news reporting, drawing on surveys, polling, referendum results, peer-reviewed
research, and clearly attested public debate. The
reference statements summarise positions supported by these sources, rather than positions generated by the models evaluated here. The first author selected five distinct stances per topic from
the linked sources. The source workbook records
a source entry for each of the 80 perspectives. The
accompanying source ledger links the evaluated
reference identifiers to their workbook cells and
preserves both the source text and any embedded
hyperlink. All reference summaries and explanations in the workbook match the evaluated reference set exactly. Source entries identify the evidence used in construction.
Reference summaries and explanations were
written in English. Sources cited for Serbian topics include English-language research, reporting,
and survey materials. The language of the cited
material was therefore not uniformly Serbian.
Each topic has five references so that all topics
share the same evaluation budget. This is a design choice, not a claim that a controversy has ex-
counterpart with a comparable political structure. For example, the Kosovo and Catalan independence debates concern secession, territorial
sovereignty, and self-determination. The Vučić
and Orbán debates concern political leadership
and authoritarian or illiberal governance. Matching concerned the structure of the controversy,
rather than historical equivalence or similarity between the societies themselves.
The procedure was investigator-guided rather
than algorithmic. A counterpart also needed
enough external material to document distinct perspectives using the same construction procedure.
